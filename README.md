# Как устроен 3D-мир в играх

Интерактивный сайт-учебник: семь коротких уроков, в каждом живая 3D-сцена.

1. **Координаты** - точка в пространстве это три числа (x, y, z)
2. **Трансформ** - позиция, поворот и масштаб, манипулятор как в Unity (W / E / R)
3. **Меш** - треугольники, вершины, нормали и уровни детализации
4. **Иерархия** - локальные и мировые координаты на примере солнца, планеты и луны
5. **Камера** - угол обзора, пирамида видимости и отсечение лишнего
6. **Свет и материал** - шероховатость, металличность и тени
7. **Игровой цикл** - deltaTime, управление роботом и сбор кристаллов

На первом экране можно кликнуть по полу, и робот пойдёт в эту точку. Так в играх работает рейкаст.

## Как открыть

В VS Code: правой кнопкой по `index.html` → **Show Preview**.
Двойным кликом из папки сайт не откроется: браузер не запускает модули JavaScript с диска, нужен локальный сервер. Live Preview его и поднимает.

Нужен интернет: three.js, шрифты и модель робота грузятся из сети.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `index.html` | текст уроков, кнопки и ползунки |
| `style.css` | оформление. Все цвета - в самом начале файла |
| `js/main.js` | запускает сцену, когда до неё докрутили |
| `js/core.js` | общее: окно со сценой, оси, свет, загрузка робота |
| `js/hero.js` | первый экран: клик по полу и ходьба |
| `js/lesson-*.js` | по файлу на каждый урок |

## Что попробовать поменять

- `js/lesson-loop.js`: `WALK` и `RUN` - скорость робота, `CRYSTALS` - где лежат кристаллы.
- `js/core.js`: `AXIS` - цвета осей.
- `style.css`: `--paper` и `--view` - фон страницы и 3D-окон.
